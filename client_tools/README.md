# כלי קצה למחשבי הישיבה (Windows Client Tools)

תיקייה זו מכילה את קבצי ההתקנה הקלים עבור מחשבי התלמידים והעמדות הציבוריות בישיבה.

---

## 🚀 איך להתקין על מחשב בישיבה (10 שניות):

1. העתק את התיקייה `client_tools` על גבי דיסק-און-קי (DOK).
2. חבר את ה-DOK למחשב הישיבה.
3. לחץ לחיצה כפולה על הקובץ **`install.bat`** (או לחץ לחיצה כפולה על `install_context_menu.reg` ואשר את הודעת ה-Windows).
4. **זהו!**

---

## 🎯 איך זה עובד?

* כשמשתמש לוחץ **לחיצה ימנית** על כל קובץ שמע (`.mp3`, `.wav`, `.m4a`), יופיע לו בתפריט:
  **`📝 השאר הערה לאחראי שיעורים`**.
* בלחיצה עליו, ייפתח הדפדפן ישירות לכתובת:
  `http://mdserver:8000/student?file=<שם_הקובץ>`
* התלמיד כותב את ההערה ("השיעור שייך לרב ערן היימן"), לוחץ שלח, וההערה מגיעה מיידית לדאשבורד של האחראי!

---

## 🗑️ הסרה:
* להסרת התפריט בכל עת, לחץ לחיצה כפולה על `uninstall_context_menu.reg`.
