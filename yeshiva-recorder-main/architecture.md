# מסמך ארכיטקטורה - מערכת אוטומציה למיון שיעורים

מסמך זה מתעד את מבנה הפרויקט, התיקיות והקבצים עבור המערכת המלאה.

## מבנה התיקיות והקבצים


## פירוט רכיבי המערכת

1. **Config (`config.py`):**
   מרכז את כל ההגדרות, שמות התיקיות, ומאפייני ה-AI במקום אחד.
2. **Audio Processor (`core/audio_processor.py`):**
   מחלץ 35 שניות ראשונות באופן יעיל ומהיר.
3. **Transcriber (`core/transcriber.py`):**
   משתמש במודל ה-ASR של `ivrit-ai` (`whisper-large-v3-turbo-ct2` ב-`int8`) לתמלול עברית ישיבתית בדיוק מקסימלי.
4. **AI Analyzer (`core/ai_analyzer.py`):**
   שולח את התמלול הנקי ל-Gemma 4 לחילוץ מהיר של שם הרב, נושא השיעור, וקביעת סטטוס הזיהוי (כולל Few-Shot Prompting).
5. **Hebrew Date (`core/hebrew_date.py`):**
   ממיר את תאריך יצירת/שינוי הקובץ המקורי לתאריך עברי (כגון `ו_אלול_תשפו`).
6. **File Manager (`core/file_manager.py`):**
   דואג לשלמות הקבצים (Checksum SHA256), מונע דריסת קבצים בעלי שם זהה, מטמיע תגיות מטא-דאטה ID3 (אמן, כותרת ואלבום עברי), ומנהל העברה בטוחה.
7. **Watcher (`core/watcher.py`):**
   מנהל את זרימת המידע המלאה מקצה לקצה.
8. **Reset Utility (`reset_data.py`):**
   מחזיר באופן אוטומטי את כל קבצי השמע מתיקיות היעד חזרה לתיקיית `data/incoming/`, משחזר את שמותיהם המקוריים ומאפס את קובץ ההיסטוריה.
